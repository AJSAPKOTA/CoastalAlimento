Menu Admin

How to publish for everyone:
  1. Add or edit dishes (and set image path or full image URL)
  2. Click Save preview to test on this browser
  3. Click Download menu.json
  4. On GitHub: open data/menu.json → replace file with your download → Commit
  5. For new photos: upload JPG/WebP into images/… or paste a public image URL in the Image field
