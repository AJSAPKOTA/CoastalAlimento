# Food images

Professional food photographs (Unsplash License — free for commercial use) are included for every menu item.

| Folder | Contents |
|--------|----------|
| `breakfast/` | Big breakfast, eggs benedict, avocado, pancakes, rolls, omelette, muesli |
| `cabinet/` | Croissants, pita, sourdough, rolls, bagels, muffins, slices |
| `coffee/` | Espresso, long black, flat white, latte, cappuccino, mocha, iced |
| `tea/` | English breakfast, earl grey, green, peppermint, chai, chamomile |
| `afternoon/` | Fish & chips, burger, pasta, salads, steak sandwich, pizza, lamb |
| `desserts/` | Cheesecake, brownie, sticky date, fruit tart, chocolate cake |

Images are referenced from `js/menu.js` via the `image` property on each dish.

To replace any photo: drop a new file with the **same filename** into the matching folder (ideally 4:3, optimised JPEG/WebP, ~800px wide).

Sources: Unsplash (Unsplash License). Attribution not required but appreciated for the original photographers.
